# Discord Avatar Monitor Bot

A Discord bot that monitors specific users for avatar changes and sends notifications.

## Features

- 🔍 Monitors specified users for avatar changes
- 🔔 Sends ping notifications when avatars change
- 📷 Displays new avatar in embeds
- ⚙️ Configurable through environment variables
- 🛡️ Error handling and logging
